# 拼图游戏 Pintu

本项目是一个基于 Java Swing 课程设计扩展而来的拼图游戏项目，当前包含 Java 桌面版和 Web 网页版两种运行形态。

## 📦 项目结构

- `/pintu.jar`: Java 桌面版可执行程序（需 Java 环境，双击即可运行）。
- `/src/`: Java 桌面版源代码。
- `/index.html`: Web 版游戏主页面入口。
- `/web/app.js`: Web 版核心逻辑、事件处理及 Supabase 接口对接代码。
- `/web/styles.css`: Web 版响应式界面及样式设定。
- `/image/`: 游戏内置图片素材库。

## ✨ Web 版功能特性

- **双游戏模式**：
  - **休闲模式**：提供智能提示功能，无时间与步数压力。
  - **挑战模式**：记录通关用时与步数，支持将成绩提交至在线排行榜。
- **自定义图片上传**：除内置素材外，支持用户上传本地图片作为拼图背景。
- **图库交互与管理**：
  - 支持通过右键菜单对已有图片进行重命名或删除。
  - 支持通过拖拽功能对图库中的图片进行重新排序。
- **难度分级**：支持 3x3、4x4、5x5 三种难度网格自由切换。

### 💻 本地开发与运行 (供开发者使用)

如果您希望在本地修改代码并运行网页版，建议启动静态 HTTP 服务器以正常加载 ES6 脚本模块：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```
启动后，在浏览器中访问 `http://127.0.0.1:8000/` 即可。

## ☁️ Supabase 排行榜配置（可选）

项目利用 [Supabase](https://supabase.com/) 实现了在线排行榜。如需开启此功能，请按以下步骤配置：

1. 在 Supabase 新建项目。
2. 打开 SQL Editor，执行本项目自带的 `supabase/schema.sql` 脚本以创建所需的数据表。
3. 获取项目的 `Project URL` 和 `anon key`，并将其填入 `web/supabase-config.js` 文件中。

*(注：如不进行上述配置，游戏将自动降级使用浏览器本地存储（LocalStorage）来记录成绩，不影响正常的游玩流程。)*
