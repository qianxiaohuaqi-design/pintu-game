# 拼图游戏 Pintu

本项目是一个基于 Java Swing 课程设计扩展而来的拼图游戏项目，当前包含 Java 桌面版和 Web 网页版两种运行形态。玩家可以在网页端体验到完整的现代界面与交互功能。

## 📦 项目结构

- `/pintu.jar`: Java 桌面版可执行程序（需 Java 环境，双击即可运行）。
- `/src/`: Java 桌面版源代码。
- `/index.html`: Web 版游戏主页面入口。
- `/web/app.js`: Web 版核心逻辑与事件处理。
- `/web/styles.css`: Web 版响应式界面及样式设定。
- `/image/`: 游戏内置图片素材库。

## ✨ 游戏玩法与功能介绍

本项目不仅保留了经典拼图游戏的核心玩法，还针对现代 Web 平台进行了全方位的体验升级。游戏主要包含以下几大核心模块：

### 1. 经典与挑战并存的双游戏模式
- **休闲模式**：专为轻松娱乐设计。在此模式下，游戏不会记录通关所用的时间与步数。若玩家遇到卡关情况，可随时点击“智能提示”按钮，系统会自动演示下一步的最优解，帮助玩家轻松完成拼图。
- **挑战模式**：面向追求极致的硬核玩家。该模式会精准记录玩家每局游戏消耗的总时间与移动步数。游戏结束后，成绩将根据所选难度自动提交至系统，玩家可借此不断突破自我记录。

### 2. 动态难度与排行系统
- **三种难度分级**：游戏支持 3x3（简单）、4x4（中等）、5x5（困难）三种不同规格的网格矩阵。拼图块数越多，还原难度越大，玩家可根据自身水平自由切换。
- **在线排行榜**：挑战模式通关后，成绩将被收录进难度专属排行榜中。排行榜默认显示该难度下的历史最佳记录，玩家可以直观地对比自己与他人的拼图实力。

### 3. 高自由度的图库定制功能
- **内置丰富素材**：游戏初始自带多个趣味主题的图片，包括萌宠（猫、狗）及各类流行表情包，供玩家快速开始游戏。
- **自定义本地传图**：除了系统预设，玩家还可以点击右下角的上传按钮，将自己喜欢的本地照片添加进图库中，生成独一无二的专属拼图关卡。
- **可视化图库管理**：
  - **拖拽排序**：在底部的图库列表中，玩家可以直接长按并拖拽图片，利用流畅的排版动画调整图库顺序。
  - **右键管理**：玩家可通过鼠标右键唤出菜单，对图库中的任意自定义图片进行安全删除，随时保持图库整洁。
